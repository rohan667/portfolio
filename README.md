# Rohan Joseph | Cybersecurity Portfolio

An immersive 3D portfolio for a computer engineering student working in cyber threat intelligence, ethical hacking and web design.

**Live site:** https://comforting-mermaid-2b6003.netlify.app

## Features
- Scroll-driven 3D flight through a data tunnel, with a new 3D object for each section (Three.js)
- Boot sequence, glitch text and a neon glow effect
- Interactive terminal: try `help`, `skills`, `projects` or `sudo hire rohan`
- Cyber Kill Chain explorer, showing how an attack unfolds and how defenders respond
- "Phish or legit?" mini-game with five fictional emails
- A small cat chasing a computer mouse across the screen
- Responsive layout that works on desktop and mobile

## Built with
HTML, CSS, JavaScript and [Three.js](https://threejs.org). There is no build step.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

The 3D scene and fonts load from a CDN, so you need an internet connection.
